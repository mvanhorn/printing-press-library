All five survivors are hand-code and are implemented as compact command behaviors. The full persona/candidate/kill/proof audit is saved beside this manifest. Closest killed alternatives included guaranteed routes, measured-clearance comparisons, universal suitability scores and background watching; source evidence cannot support those.

## Source/tool evidence
Focused GitHub plugin/MCP/CLI/skill/workflow, npm wrapper/CLI, PyPI library and MCP-directory searches returned no existing WheeLog integration. The official external plugin catalog contains no WheeLog entry. No SDK or repo was available for issue/DeepWiki analysis. Wheelmap's official FAQ informed explicit unknown and separate equipment evidence; it is not a data source in this CLI.

## Limits and persistence
Only source name/address/category/public facility coordinates/record dates and aggregate question reports enter output or the local store. No raw profiles, comments/photos/narratives or personal histories. Numeric dimensions and individual report dates remain unavailable. Two observations per selected spot; at most 50 selected spots, bounded requests/pages/response sizes/runtime. No route or availability claims.

## Pre-generation decisions
Category travel. Standard HTTP, anonymous, browser-observed headers. MCP stdio only. No cache auto-refresh; the local shortlist is explicit user working state. The learn block contains source category vocabulary and aliases.
