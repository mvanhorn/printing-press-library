# Anonymous discovery proof
Goal: fetch and filter public exhibitions for itinerary discovery.
Isolated agent-browser session tab-cli-discovery opened /en/events, then /en/events/filter/open and waited for network idle; closed after capture. No login/session used. The second HAR recorded 165 requests; retained only CDN data routes with credentials removed. Website request parameters establish content_type event, locale *, skip/limit, scheduleStartsOn/scheduleEndsOn, categories and linked venue filters. CDN redirects were replayed by direct GET without access_token: 307 then 200 JSON. Hasura public aggregate requests were observed but omitted from runtime to avoid popularity claims and extra requests. Public app bundle field names informed the contract; bundles were deleted after extracting names. Some initial HAR responses were unfinished, repaired with direct response samples. No rate limiting observed; bounded discovery requests used sequential batches of at most 3.
