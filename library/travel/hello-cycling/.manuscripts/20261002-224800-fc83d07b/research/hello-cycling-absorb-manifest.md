# HELLO CYCLING absorb manifest
User batch instructions preauthorize the focused public-source scope and routine gate choices. The exactly-one-reviewer constraint overrides the Press brainstorm-subagent step; builder makes scoped domain choices directly. No extra agent is spawned here. Five novel workflows are hand-written Go; all ship, no stubs. Model eligibility and final ride prices stay in app because source GBFS type 2 is generic electric-assist.
