# Browser search access and source evidence

Observed 2026-09-28 after the user completed Activity Japan's human verification in Firefox. Capture was restricted to one `en.activityjapan.com` search document; its temporary HAR and saved HTML were deleted after extracting non-secret metadata. See `search-request-sanitized.json` for the URL, status and cookie **names only**.

- English Kyoto search `/search/kansai/kyoto/` loaded HTTP 200 with 545 reported results. The 2026-10-03 date link uses `joinDayFromCalendar=2026/10/03` and displayed 245 results. Plan 62375 appeared with operator link, category, `2,000 JPY → 1,800 JPY～`, age 2–100 and a source plan URL. Its plan ID and headline amount matched the anonymous detail endpoint; 2026-10-08's selected-date source quote was 1,800 JPY for option 176511.
- The page's detailed form names include `joinDayFromCalendar`, `addressAndKeyword`, `basicTargetAge`, `searchPeople`, `searchBudgetFrom`, `searchBudgetTo`, `stock_flag`, `searchCourse[...]`, `searchEquipment[...]`, `searchTargetLevelUser[...]`, and `searchOtherUser[...]`. Category and area selection also use indexed paths. These are browser UI observations, not a replayable CLI search API.
- English Osaka cooking search `/search/food-making/kansai/osaka/` loaded with 16 reported results. Plan 62061 appeared as “Sushi & Matcha Making Experience”, operator “Sushi Master Namba Dotonbori”, headline 9,000 JPY, broad plan age 0–99, and start labels 14:00/16:00. CLI detail returned the same plan ID; its dated price data distinguished adult 9,000 JPY, child 7,000 JPY and infant 0 JPY options. The adult-only derived subtotal for two is 18,000 JPY before unknown fees.
- English Osaka food-tour search `/search/foodtour-barhopping/kansai/osaka/` displayed 13 results including food venues and guided tours. Category result membership can be broader than an agent's intent; a source category match is not a quality judgment.
- Direct anonymous terminal GET to the same English Kyoto listing returned HTTP 403. Replaying the user's temporarily authorized Activity Japan search cookies and Firefox user agent from the single-request HAR still returned an AWS WAF HTTP 202 challenge. The public `gd.activityjapan.com` host returned HTTP 200 for the same search path but only a 404 fallback page, not search results. The contracted partner API requires an NDA and commercial agreement. Thus destination/category listing search is clearance-gated and unavailable to the independent CLI; it is not claimed as shipped.

No session cookie or clearance-token value is retained in the repository or evidence files. These observations substantiate filter names and search-to-detail identity, but do not turn fixture/browser-only search into CLI live search verification.
