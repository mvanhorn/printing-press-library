# Public helper receipts

The reviewer helper sources in these manuscript folders document isolated executions against the exact cached Printing Press SDK. They are proof receipts, not additional published CLI modules. Public go.mod/go.sum copies use a .receipt suffix and generalized local paths so they cannot be mistaken for installable library modules. Private original module files, execution commands, source/artifact/helper hashes, ledger and reviewer provenance remain intact.

Hash statements in the review receipts identify those preserved private originals. Public generalized copies are explanatory artifacts and are not claimed byte-identical executable reproductions. Reproduction requires resolving a local cached SDK path from the preserved private recipe; no product source, runtime harness, acceptance marker or supply-chain check was changed.
