
COMMAND  EXIT 0
Plan Japan luggage forwarding with source rates, calendar deadlines and acceptance evidence.

Highlights (not in the official API docs):
  • parcel   Classify both size and weight and preserve acceptance unknowns.
  • quote   Fetch current source rates and date-specific arrival or shipping deadline.
  • airports   Use live upstream airport codes and Japanese terminal names.
  • counters   Inspect public send/pickup/floor evidence and fingerprint-checked image hours.
  • same-day   Inspect limited-area cutoff schedules and separate example prices.
  • products   Review live service policy evidence for standard, airport, roundtrip and same-day products.

Agent mode: add --agent to any command for JSON output + non-interactive mode.
Health check: run 'yamato-pp-cli doctor' to verify connectivity.
See README.md or the bundled SKILL.md for recipes.

COMMAND quote EXIT 0

Source dates are estimated and local dispatch cutoff times remain unknown. Rates are tax-inclusive list tariffs per parcel; conditional discounts and packaging are not automatically applied. Use parcel to determine the chargeable size from both measured dimensions and weight.

COMMAND which EXIT 0
which resolves a natural-language capability query (for example, "search messages" or "stale tickets") to the best matching command from this CLI's curated feature index.

Exit codes:
  0  at least one match found
  2  no confident match - the query did not score against any indexed capability; fall back to '--help' or 'search' if this CLI has one. Machine output (--json/--csv/--plain/--quiet, or a pipe) still exits 2 and writes {"matches":[]} (or the equivalent empty table) to stdout.

Usage:
  yamato-pp-cli which [query] [flags]

Examples:
  yamato-pp-cli which "stale tickets"
  yamato-pp-cli which "bottleneck"
  yamato-pp-cli which --limit 1 "send message"
