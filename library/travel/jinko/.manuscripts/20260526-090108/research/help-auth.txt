Manage authentication credentials.

Usage:
  jinko auth [command]

Available Commands:
  login       Authenticate with Jinko (paste your API key).
  logout      Clear stored credentials.
  status      Show current authentication status.

Flags:
  -h, --help   help for auth

Global Flags:
      --api-key string   API key (jnk_...) — overrides JINKO_API_KEY env and config file
      --format string    output format: json | table (default "json")

Use "jinko auth [command] --help" for more information about a command.
