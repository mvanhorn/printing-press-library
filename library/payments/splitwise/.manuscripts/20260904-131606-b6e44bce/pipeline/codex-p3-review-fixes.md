## Background (verified facts)
4.31.7's generated `printCSV`/`printPlain` (helpers.go `tabularObjectRows`) flatten ANY non-array object into ONE row
whose cells are Go-formatted (`[map[currency:USD net:4]]`). The hand wrapper `(*rootFlags).emitStructured`
(internal/cli/splitwise_output.go) already guards its callers: single-array envelopes unwrap to a table, anything
else prints the JSON document. But many hand commands still call `flags.printJSON(cmd, v)` directly and therefore emit
garbage under `--csv`/`--plain` — e.g. `net --csv` on an empty store prints `by_currency,plan,savings,you_id` /
`[],[],[],0`. Also `emitStructured`'s csv/plain branches ignore `--select`/`--compact` (only the JSON branch reaches
`filterFields`), and three not-found paths print `Error:` on stderr with empty stdout under `--json` while `settle-up`
emits a JSON error envelope via `novelErr`.
