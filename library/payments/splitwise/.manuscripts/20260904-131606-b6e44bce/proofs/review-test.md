A green suite ships it because nothing invokes a command with `--csv`. Scenario: an agent/CDR recipe `net --csv` or `report --csv` gets unparseable cells containing friend names and amounts mashed into `map[…]` text. Fix (code): route these five through `flags.emitStructured` (same one-line change as ledger). Fix (test): add `TestHandCommandsCSVNeverFlattenObjects` — table over `{activity --since 30d, audit, balances, balances --by-currency, balances --by-group, debts, fairness, forecast, ledger "Group Alpha", ledger --friend "Pat Two", net, normalize --rate EUR=1.1, recurring, report --group "Group Alpha", spend, brief, resolve Pat, settle-up "Group Alpha", split "Group Alpha" --amount 84 --equal, fairness nudge "Friend One"}` on `seedSyntheticStore`, for each of `--csv`/`--plain`: assert stdout is either a JSON document (`json.Valid` after TrimSpace, first byte `{`/`[`) or parses with `encoding/csv` (or splits on tabs) **and no cell contains `map[` or `[map[`**. This fails today for exactly the five commands above and pins the shape for every other one.
