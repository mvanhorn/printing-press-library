## [WARNING]

Measured on the mirror, annualized money-market funds, column "30 Days": 2026-09-04 118 parsed / 116 kept, dropped {-1.93, -0.18}; 2026-09-03 144 parsed / 142 kept, dropped {-1.92, -0.20}. Column "1 Day" 2026-09-03 drops -0.37. A money-market fund at -1.93% annualized over 30 days is a real observation and is exactly the fund a short-rate proxy should show in the left tail; it is deleted by the same rule that deletes the -1622.22 artefact. This is the same left-tail-removal bias the endpoint contract calls the run's most dangerous finding (section I), reintroduced one layer downstream of the parser that was fixed for it. Median impact is small (~0.01-0.02pp) but p10 and fund_count are both biased and unauditable. Suggest a symmetric band plus an `implausible_rows` field alongside `fund_count`.

## [WARNING]
exposure.go:600-601 and 678-684 — exposure has no equivalent of the `allEmpty` guard that backfill.go:880-904 applies. backfill refuses to commit a month in which every fund returned MUFAP's empty-200 shape, on the stated grounds that that shape is indistinguishable from a rejected parameter or an expired session. exposure instead books every such fund as `Absent`, so a total outage yields stocks_pkr_million 0, net_assets_pkr_million 0, equity_share 0, fund_count 0, absent_funds N, fetch_failures [] — a clean-looking zero-equity month. The human path (exposure.go:678-684) then explains it as 'MUFAP publishes allocation per fund-month; older months are often absent entirely', and the 'This run did not complete' caveat prints only when `unfinished > 0 || amcsFailed > 0`, neither of which is true for an all-empty-200 run. Suggest flagging `absent_funds == funds_attempted` the way backfill does.
