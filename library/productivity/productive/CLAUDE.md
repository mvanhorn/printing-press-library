# Maintainer notes (productive-pp-cli)

This CLI was generated by the `printing-press` skill from an internal JSON:API spec,
then extended by hand. `AGENTS.md` (imported above) documents the generated CLI for
agents. This section covers the **hand-built parts** that are not obvious from the
generated code and that a naive `printing-press generate --force` could disturb —
read before regenerating.

## Two-header auth (critical)
Productive requires **two** headers on every request: `X-Auth-Token` (from
`PRODUCTIVE_API_TOKEN`) and `X-Organization-Id` (from `PRODUCTIVE_ORGANIZATION_ID`).
The generator models only single-header auth, so the org header is hand-wired:
- `internal/config/config.go` — `ProductiveOrganizationId` field, env load, and
  `applyOrgHeader()` which injects `X-Organization-Id` into `Config.Headers` (applied
  to every request by `client.do()`).
- `internal/cli/doctor.go` — org-id presence check.
- `internal/client/client.go` — dry-run preview renders `Config.Headers` so
  `--dry-run` shows both headers.

## Financial reconciliation commands (hand-authored)
- `internal/cli/productive_reports.go` — shared JSON:API report helper: paginates
  `/reports/financial_item_reports` (report rate limit is 10 req/30s — throttled),
  resolves budget names via `include=budget`. Period field is `date_period`
  ("2026/M03"); money is integer cents.
- `recognized_revenue.go`, `invoiced.go`, `reconcile.go`, `aging.go` — the novel
  commands. `reconcile` joins recognized vs invoiced by budget×period.

## Generic write surface (hand-authored)
- `internal/cli/productive_write.go` — `create`/`update`/`delete` build the JSON:API
  `{data:{type,attributes,relationships}}` envelope from `--set`/`--set-json`/`--rel`/
  `--data` and send `application/vnd.api+json`. This fills two generator gaps: no PATCH
  emission and no JSON:API body envelope. `dogfoodGuard` prevents live mutation during
  `dogfood --live`.

## Other hand-edits
- `internal/cli/deals_list.go` — `normalizeStageType` maps `deal`/`budget` → `1`/`2`.
- `internal/cli/channel_workflow.go` — `workflow archive` curtails to 3 resources under
  `PRINTING_PRESS_DOGFOOD=1` so the full 48-resource archive doesn't hit the 30s test
  timeout (real runs archive everything).
- Generated example command paths were corrected from underscores to hyphens for
  multi-word resources (e.g. `line-items`, not `line_items`). *(Generator bug.)*
