# Webhook capability and network boundary

The webhook client must block CGNAT, zero-net, protocol-assignment, benchmarking, reserved IPv4, NAT64, and 6to4 carrying blocked IPv4, including after DNS resolution. Capability paths, query strings and userinfo never belong in human output or error strings. JSON list preserves the explicit URL contract. A redirect must not reintroduce a signature copied from the initial request on subsequent hops. Signing secrets can be read from a bounded first stdin line; registration consent reads the next line from the same buffer.
