```
between resource "users" endpoint "email" and resource "users" sub-resource "email"
```

Cause: Swagger has both `GET /users/email` (flat endpoint, name `email`) and
`PUT /users/{userId}/email` (sub-resource `email`). Both derive
`internal/cli/users_email.go`. The prior (pre-guard) print silently dropped one.

Fix: renamed the flat operation's `operationId` from `userEmail` to
`userEmailCheck` in `research/zoom-openapi-v2.json`. Endpoint now derives as
`users email-check`; wire path unchanged. **Systemic — retro candidate:** the
generator should auto-disambiguate a flat endpoint against a same-named
sub-resource rather than hard-blocking generation.

### Adaptations

1. **`github.com/ledongthuc/pdf`** re-added to `go.mod` (`notesparse` dependency;
   fresh generate does not know about it).
2. **auth collision.** 4.29.0 emits `internal/cli/auth.go` with
   `newAuthSetTokenCmd` / `newAuthStatusCmd` / `newAuthLogoutCmd`; the prior print
   had no generated auth.go and hand-owned all three. Resolution: kept the fresh
   generated `auth` command (framework: `setup`, `status`, `set-token`, `logout`)
   and re-expressed the Zoom-specific S2S OAuth exchange as siblings attached via
   a new `attachZoomS2SAuth(authCmd, flags)` helper:
   - `auth set-token`  -> `auth s2s-token`  (account_credentials exchange)
   - `auth status`     -> `auth s2s-status` (token-cache state)
   - `auth refresh`    -> unchanged
   - hand-authored `auth logout` dropped (framework equivalent kept)
   - `redact()` renamed `redactS2SID()` to avoid framework collisions.
3. **config token-cache patch re-applied.** The prior print had a hand edit in the
   generated `internal/config/config.go` calling `tryLoadCachedZoomToken()`. Fresh
   generate lost it, which would have broken every cloud command after
   `auth s2s-token`. Re-applied after the `ZOOM_S2S_ACCESS_TOKEN` env block,
   populating `cfg.ZoomS2sAccessToken` from the cache.
   **Systemic — retro candidate:** there is no generator hook for a
   CLI-specific credential resolver, so this patch must be hand-reapplied every
   reprint.
4. **Novel scaffolds removed.** The generator emitted 7 parent + 10 leaf
   `TODO: implement novel feature` scaffolds (plus their `_test.go` siblings) for
   the research.json novel features. All were deleted in favour of the real
   hand-authored implementations, and `root.go` was rewired from
   `newNovel*Cmd` to `newZoom*Cmd`.
5. `// pp:data-source <local|live|auto>` headers added to all carried novel
   command files (the prior print predated the convention).
