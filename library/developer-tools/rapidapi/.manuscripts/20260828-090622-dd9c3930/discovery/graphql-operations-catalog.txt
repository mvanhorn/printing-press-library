## Input shapes (validated)
- SearchApiWhereInput: { term, categoryNames: [String], tags: [String], privateApisJwt, contextId, contextType }
- SearchApiOrderByInput: { sortingFields: [{ by: "ASC"|"DESC", fieldName: "ByRelevance"|"ByAlphabetical"|"ByUpdatedAt"|"installsAllTime" }] }
- PaginationInput: { first, last, after, before }  (relay-style, NOT limit/offset)
- MetricsInput: { fromDate: DateTime!, toDate: DateTime! }
- GetSubscriptionInput: { statuses: [String], limit: Int }
- ApiInfo fragment: __typename id name title description visibility slugifiedName pricing updatedAt category thumbnail isSavedApi categoryId apiCategory { name color } score { popularityScore avgLatency avgServiceLevel avgSuccessRate }
- EndpointInfo fragment: id isGraphQL route method name description apiversion group index
- BillingPlanInfo fragment: id name recommended visibility allowedPlanDevelopers
- BillingPlanVersionInfo: id name period option price currency current billingPlanId pricing localePrice
- ApiSubscriptionInfo: id status userId parentId billingPlanVersionId apiId apiVersionId stripeId createdAt canceledAt mashapeId billingPlanVersion { billinglimits }
- notification fragment: id type createdAt isRead title body callToAction image any
- Gateway fragment: id dns type status version isDefault lastActive serviceStatus
- ApplicationAuthorization: id key name status updatedAt grantType applicationId authorizationType authorizationValues gateways
