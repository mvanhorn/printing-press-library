## Process note

Finding 1 was originally reported by the Phase 4.8 SKILL reviewer and **wrongly rejected** during that phase. The rejection rested on `auth set-token --help` exiting 0 — but Cobra falls through to the parent's help on an unknown subcommand, so exit 0 proved nothing. The correct check is the `Usage:` spec line, which read `webflow-pp-cli auth [flags]` rather than `auth set-token [flags]`. This is the exact failure mode the Phase 3 completion gate documents; it was applied to novel commands during Phase 3 but not to this ad-hoc verification. Two independent reviewers converging on the same finding is what surfaced the error.
