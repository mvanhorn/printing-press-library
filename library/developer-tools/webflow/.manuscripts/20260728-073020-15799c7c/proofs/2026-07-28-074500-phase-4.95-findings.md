## The finding that changed the shape of the CLI

The review surfaced, and I independently confirmed, that **generated sync cannot reach `collections`, `redirects`, or an unqualified `items`**:

```
sync --resources collections → Error: 1 resource(s) failed to sync: collections
sync --resources redirects   → Error: 1 resource(s) failed to sync: redirects
sync --resources items       → WEBFLOW_COLLECTION_ID not set
```

`Upsert*` methods and `CREATE TABLE` statements exist for all three, but neither `syncResourcePath` nor `dependentResourceDefs()` enumerates them. Consequence before the fix: `redirects audit` could never audit anything, `collections completeness` could never detect a required-field gap, and `overview` printed `unpublishedItems: 0` while `publish preview` reported the true count from the same mirror, with no explanation.

**Resolution — five of seven commands now fall back to scoped live reads.** Not a scope downgrade: the transcendence rationale was always local *computation* (self-joins, cross-entity checks, aggregation) that no endpoint performs. Only the fetch source moved.

| Command | Fetch cost when the mirror is empty |
|---|---|
| `redirects audit` | 1 GET per site |
| `collections completeness` | 1 GET schema + paginated items, `--max-scan-pages` |
| `drift` | paginated items for one collection, `--max-scan-pages` |
| `items bulk-set` | paginated items for one collection, `--max-scan-pages` |
| `publish preview` | collections + items per collection, bounded by `--max-collections` and `--max-scan-pages` |
| `overview` | **stays local-only** — cross-site × per-collection fan-out at 60 req/min is exactly what the Phase 1.5 adversarial cut killed other candidates for |
| `seo audit` | **stays local-only** — `sites_pages` is syncable, so it already worked |

`overview` now reports `collections`, `unpublishedItems`, and `redirects` as **null rather than 0**, with a note pointing at `publish preview` for a live per-site answer. A zero that contradicts a sibling command is worse than an honest gap.

**Missing-credential behavior.** A 401/403 during a live fallback degrades to the command's own zero-valued view plus an actionable note, exit 0 — a configuration state, not a crash. Everything else (5xx, transport, malformed body) still propagates as an error.

## Dimensions the review checked and found clean

Drain-first discipline (every path drains, checks `rows.Err()`, closes before the next query); NULL-safety (`sql.NullString` on every nullable column); empty-slice marshalling (`make([]T, 0, n)` throughout); SQL injection (every user value is a bound `?`; the one `%q` identifier interpolation draws from a closed two-element literal list, now commented as such); credential handling (no token, cookie, or auth header printed or persisted); `--db` path traversal (DSN opens `mode=ro`); `normalizePath` panic-safety; `hasUnpublishedChanges` boundary cases.

## Template-shape — filed for retro, not patched

1. **`collections`, `sites_collections`, and `redirects` are unreachable by generated sync** while their `Upsert*` methods and `CREATE TABLE` statements exist. Clean generator bug with a clean repro. Recorded as a reprint guard in `.printing-press-patches/`.
2. **`store.go` DSN string concatenation** — `"file:" + dbPath + "?mode=ro&…"`; a `--db` value containing `?` injects DSN parameters. Generated file; `sync` passes the same unvalidated flag.
3. **`helpers.go` `truncate`** slices at `s[:max-3]`, splitting UTF-8 runes, so a non-ASCII site or collection name renders as mojibake in three call sites.
4. **Generated `doctor.go`** tells users to "run auth set-token or auth logout" — `auth set-token` does not exist in the emitted CLI.

## Remaining, accepted

- `cliutil.RateLimitError` is declared but never constructed anywhere in the generated tree. The CLI now matches on `APIError.StatusCode` instead, but the unused type is a generator-side loose end.
- `which "list sites"` returns `{"matches":[]}` with exit 0 though its help documents exit 2 for no confident match; the index covers only novel features. Generator-owned.
- Threshold flags (`--title-max -5`, `--limit -1`) silently disable their check rather than erroring. Low impact; left as-is.
