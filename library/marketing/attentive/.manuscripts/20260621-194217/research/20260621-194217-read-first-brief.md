# Attentive read-first brief

Source: official Attentive V2 OpenAPI spec at `https://docs.attentive.com/openapi/attentive-api-bundled-v2.yaml`.

The generated CLI focuses on Attentive segment discovery, segment lookup, user-attribute submission, and bulk job status inspection. The local spec copy removes OAuthFlow alternatives from endpoint security because this generated CLI uses bearer-token auth and does not implement OAuth scope negotiation.

Live vendor behavior was skipped because credentials were not available.
