# Marketo Engage read-first brief

Marketo Engage was selected as a marketing automation system with useful read surfaces for leads, activities, campaigns, and lists.

The generated package intentionally emphasizes read-first agent workflows: local sync, search, analytics, command discovery, and MCP access. Live vendor behavior is credential-gated, so local validation covers build health, command surfaces, auth diagnostics, and MCP startup.

The default server URL uses `https://example.mktorest.com/rest` as a placeholder because Marketo REST hosts are instance-specific. Users should configure their instance base URL before live calls.
