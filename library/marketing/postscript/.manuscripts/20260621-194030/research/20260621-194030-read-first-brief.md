# Postscript read-first brief

Source: official Postscript `llms.txt` index at `https://developers.postscript.io/llms.txt` and the current v2 ReadMe reference pages linked from it.

Postscript does not expose a single public OpenAPI bundle at `/openapi.json`; each reference Markdown page contains an embedded OpenAPI definition. The compact local spec combines the six documented v2 reference endpoints for subscribers, custom events, unsubscribe, and redact.

Live vendor behavior was skipped because credentials were not available.
