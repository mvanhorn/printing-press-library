# Meta Ads Library CLI Brief

## API Identity
- Domain: Advertising intelligence, creative research, ad transparency, competitive marketing analysis
- Users: Performance marketers, growth teams, creative strategists, agencies, e-commerce operators, media buyers, political/transparency researchers, and AI agents auditing competitor ad funnels
- Data profile: High-volume public ad creatives (copy bodies, headlines, link captions, CTAs, landing URLs, images, videos, carousel cards, collation counts, start/stop timestamps, publisher platforms across Facebook, Instagram, Messenger, Threads, Audience Network), advertiser/page identities (page IDs, categories, likes, IG handles, verification), plus regulated transparency data (EU/UK/BR reach, age/gender breakdowns, beneficiary/payer records, political spend & impression brackets, bylines)
- Homepage: https://www.facebook.com/ads/library/ (Meta's official public Ad Library web portal; official API documentation verified at `https://developers.facebook.com/docs/graph-api/reference/ads_archive/` and `https://developers.facebook.com/docs/graph-api/reference/archived-ad/` via `fetch-docs.sh`, HTTP 200)
- Data sources: none (single-service CLI covering Meta Ad Library's public GraphQL surface and Meta's official Graph API `v27.0/ads_archive` endpoint)

## Reachability Risk
- **Low (with homepage bootstrap)** for public Meta Ad Library GraphQL, **None** for Official Graph API `ads_archive`:
  - `https://www.facebook.com/ads/library/api/` returned HTTP `403` on raw `fetch-docs.sh` (JS challenge).
  - `probe-reachability` on `https://www.facebook.com/ads/library/?active_status=active&ad_type=all&country=US&q=nike&search_type=keyword_unordered` returned `mode: browser_clearance_http` (HTTP `403` on both `stdlib` and `surf-chrome` because Meta serves a JS challenge on the `/ads/library/` HTML route).
  - **Key breakthrough (verified live 2026-11-27):** Bootstrapping session cookies (`datr`, `fr`, `sb`) and `lsd` / `__spin_r` tokens from `GET https://www.facebook.com/` (HTTP `200`, 381 KB HTML on plain stdlib HTTP) unlocks **all three public Ad Library GraphQL queries** on `POST https://www.facebook.com/api/graphql/` with HTTP `200`, zero errors, zero browser, zero login, and zero API key:
    - `useAdLibraryTypeaheadSuggestionDataSourceQuery` (`doc_id: 9755915494515334`) -> 200 OK, 15 advertiser pages returned (`Nike`, `page_id: 15087023444`)
    - `AdLibrarySearchPaginationQuery` (`doc_id: 25464068859919530`) -> 200 OK, active US commercial ads returned with full `snapshot`, `collation_count`, `publisher_platform`, pagination cursor
    - `AdLibraryV3AdDetailsQuery` (`doc_id: 25068828942793558`) -> 200 OK, full `ad_details` (`aaa_info`, `advertiser`, `insights`, `transparency_by_location`, `violation_types`)
  - **Official Graph API (`https://graph.facebook.com/v27.0/ads_archive`)**: Direct HTTP `400` JSON without token (clean API reachability); requires `META_ACCESS_TOKEN` (verified Meta ID + developer app). Known GitHub issues on `facebookresearch/Ad-Library-API-Script-Repository` (#50, #59, #61) confirm two structural quirks: (1) official `ads_archive` returns empty `[]` for non-EU commercial ads (only political/issue ads globally + all ads in EU/UK/Brazil), and (2) `eu_total_reach` or EU-only fields can error or return null depending on token/region, requiring graceful FULL -> CORE field fallback. Rate limits return Graph error code `613` and public GraphQL rate limits return error code `1675004`.

## Top Workflows
1. **Competitor Ad Spy & Creative Teardown (Global Commercial Ads)**: Resolve a brand name to its Facebook Page ID (`advertisers` / typeahead), pull every active ad running across Facebook/Instagram/Threads/Messenger/Audience Network in any country (US, MX, EU, etc.), inspect copy hooks, CTAs, landing page domains (unwrapped from `l.facebook.com`), media formats (video vs static vs carousel), and collation scale counts.
2. **Winner & Longevity Detection**: Identify which ads a competitor has kept running the longest (30/60/90+ days = proven profitable winners) and which creatives have the highest active collation/variant count (`ads_using_creative`).
3. **Advertiser Change Monitoring (Diff Over Time)**: Sync an advertiser's active ads into a local SQLite archive over days/weeks and diff snapshots to see exactly what new hooks/creatives launched, which ads were paused/killed, and how active ad volume shifted.
4. **Cross-Competitor Creative & Funnel Comparison**: Compare 2–5 competitors side by side on active ad volume, video-vs-image mix, creative refresh velocity, CTA distribution, platform mix, and landing page URL patterns.
5. **Official EU/UK/Political Transparency & Spend Audits**: Query Meta's official Graph API `v27.0/ads_archive` (when `META_ACCESS_TOKEN` is configured) or `AdLibraryV3AdDetailsQuery` for EU total reach, age/gender/country breakdowns, beneficiary/payer disclosures, political bylines, spend brackets, and impression ranges — plus local media download from ad creatives.

## Data Layer
- Primary entities: `ads` (archived/active ads with normalized copy, headline, CTA, landing URL/domain, media URLs, format, platforms, collation count, start/stop dates, active status, spend/impression/reach brackets, raw JSON), `advertisers` (Facebook pages with page ID, name, category, likes, IG handle, verification, last synced), `snapshots` (point-in-time advertiser ad-set captures enabling exact launched/stopped/persisted diffs over time), `ad_details` (EU/UK/BR transparency, payer/beneficiary, demographic breakdowns)
- Sync cursor: Per-query / per-advertiser pagination cursor + timestamped advertiser snapshots in SQLite so `diff`, `winners`, and `compare` work instantaneously offline
- FTS/search: SQLite FTS5 full-text index across `page_name`, `body_text`, `link_title`, `link_caption`, `link_description`, `cta_text`, `landing_domain`, `landing_url`, and `bylines` — enabling instant offline searches like "every active competitor ad mentioning 'free shipping' or sending traffic to a quiz funnel"

## Codebase Intelligence
- Sources: Direct source inspection of `promisingcoder/MetaAdsCollector` (`client.py`, `constants.py`, `models.py`, `cli.py`), `thenavidm/facebook-ad-library-mcp-cli` (`src/app.ts`, `src/archive/client.ts`), `RamsesAguirre777/facebook-ads-library-mcp`, `Paularossi/AdDownloader`, and official Meta Graph API v27.0 docs (`developers.facebook.com/docs/graph-api/reference/ads_archive/` and `/archived-ad/`).
- Auth:
  - **Public GraphQL surface**: Zero API key, zero login. Bootstraps cookies (`datr`, `fr`, `sb`) + `lsd`, `__spin_r`, `__spin_t`, `__spin_b`, `__hsi`, `__hs`, `__comet_req`, `v` from `GET https://www.facebook.com/`, computes `jazoest = 2 + sum(ord(c) for c in lsd)`, sends `POST https://www.facebook.com/api/graphql/` with `fb_api_caller_class=RelayModern`, `x-fb-lsd`, `x-fb-friendly-name`, and strips Facebook's `for (;;);` anti-XSSI prefix. Never sends stale hardcoded `__dyn`/`__csr` fallbacks (causes error `1675004`). Refreshes session automatically on HTTP `403` or session errors `1357001`/`1357004`.
  - **Official Graph API surface**: Optional `META_ACCESS_TOKEN` (with fallback to `META_ADS_ARCHIVE_TOKEN` / `FACEBOOK_ACCESS_TOKEN`) passed as `access_token` query parameter to `GET https://graph.facebook.com/v27.0/ads_archive`. Automatically falls back from full 23-field projection to core 12-field projection if the token lacks EU-only field permissions.
- Data model: GraphQL `search_results_connection.edges[].node.collated_results[]` contains `ad_archive_id`, `collation_id`, `collation_count`, `page_id`, `page_name`, `is_active`, `start_date`, `end_date`, `publisher_platform`, `currency`, `spend`, `impressions_with_index`, `reach_estimate`, `snapshot` (`body.text`, `title`, `caption`, `link_url`, `link_description`, `cta_text`, `cta_type`, `display_format`, `images[]`, `videos[]`, `cards[]`, `page_categories`, `page_like_count`, `page_profile_uri`). Official `ArchivedAd` returns `id`, `page_id`, `page_name`, `ad_creation_time`, `ad_delivery_start_time`, `ad_delivery_stop_time`, `ad_snapshot_url`, `ad_creative_bodies`, `ad_creative_link_titles`, `ad_creative_link_captions`, `ad_creative_link_descriptions`, `publisher_platforms`, `languages`, `bylines`, `currency`, `spend`, `impressions`, `demographic_distribution`, `delivery_by_region`, `estimated_audience_size`, `eu_total_reach`, `br_total_reach`, `total_reach_by_location`, `age_country_gender_reach_breakdown`, `target_ages`, `target_gender`, `target_locations`, `beneficiary_payers`.
- Rate limiting: Public GraphQL returns error code `1675004` on rate limits; add polite jittered pacing between paginated pages and exponential backoff on 429/`1675004`. Official Graph API returns error code `613` and tracks `object_count_pct` headers.
- Architecture: Combining a zero-dependency Go pure-HTTP GraphQL client (automatic `facebook.com` homepage `lsd` handshake — no Playwright/Chromium required!) with the official Graph API `v27.0/ads_archive` client AND a local SQLite FTS5 store eliminates the two biggest flaws of every existing tool (heavy browser dependencies OR US/global commercial ad blindness).

## Product Thesis
- Name: `meta-ads-library-pp-cli` (display name: **Meta Ads Library**)
- Why it should exist: Every existing Meta Ad Library tool forces a painful tradeoff: official Graph API wrappers (`AdDownloader`, `facebookresearch`) cannot see US/LATAM/global commercial ads at all, while Playwright-based MCPs (`thenavidm`, `RamsesAguirre777`) drag a 400 MB headless Chromium dependency and 9-second page-hydration waits into every query, and Python scrapers (`MetaAdsCollector`) lack an offline SQLite FTS5 intelligence layer and official Graph API integration. `meta-ads-library-pp-cli` is a single fast Go binary that queries **all commercial ads globally with zero API key and zero browser**, seamlessly layers in **official `v27.0/ads_archive` spend/reach/EU transparency** when `META_ACCESS_TOKEN` is set, and compounds every run into a local SQLite database for winner detection, advertiser diffs, creative hook teardowns, and cross-competitor benchmarks.

## Build Priorities
1. **Zero-auth Global Ad Search, Advertiser Typeahead & Ad Details** (`ads search`, `advertisers search`, `ads details`, `ads url-parse`) via pure-HTTP `facebook.com` homepage `lsd` bootstrap + `POST /api/graphql/` (with automatic session refresh, `l.facebook.com` redirect unwrapping, and deep link generation).
2. **Official Meta Ad Library Graph API (`v27.0/ads_archive`)** (`archive search`) supporting all 15 query parameters, all 23 `ArchivedAd` fields, optional `META_ACCESS_TOKEN`, and graceful FULL -> CORE field retry for EU/UK/BR/political transparency and spend brackets.
3. **Compounding Local SQLite + FTS5 Intelligence & Media Workflow**: snapshot persistence (`sync`), advertiser change diffing (`diff`), ad longevity/winner ranking (`winners`), cross-competitor creative & funnel teardown (`compare`, `hooks`, `funnels`), offline FTS5 search (`search`), and creative media downloader (`media download`).
