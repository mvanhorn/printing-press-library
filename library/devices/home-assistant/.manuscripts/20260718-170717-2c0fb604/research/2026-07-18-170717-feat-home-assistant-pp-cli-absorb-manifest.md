# Home Assistant Absorb Manifest

## Sources
- [home-assistant-ecosystem/home-assistant-cli](https://github.com/home-assistant-ecosystem/home-assistant-cli) — Python, 575 stars, active, 14 top-level command families and mature output/completion ergonomics.
- [homeassistant-ai/ha-mcp](https://github.com/homeassistant-ai/ha-mcp) — Python, 4,019 stars, active, 87 published MCP tools spanning control, configuration, diagnostics, and Home Assistant administration.
- [Home Assistant REST API](https://developers.home-assistant.io/docs/api/rest/) and [WebSocket API](https://developers.home-assistant.io/docs/api/websocket/) — canonical transport/auth contracts.

### Adversarial cuts
- Scene delta — absorbed into the safer `mode run` preview/apply/verify workflow.
- Restorable checkpoint — generic restoration semantics would be misleading across domains.
- Playback ambience binding — normally a one-time automation-creation task rather than a weekly compound command.
- Guest-ready check — a preset over `house check` and `mode run` without distinct data leverage.
- Naming cleanup planner — subjective suggestions need policy/NLP; deterministic checks belong in `routine lint`.
- Room pulse — a narrow area-filtered projection of current state.
- Continuous anomaly watcher — requires a persistent process and an unverifiable anomaly model.

## Research Risks
- No user server URL or long-lived token is present, so live dogfood must be skipped under the auth-required/no-credential rule unless credentials are supplied later.
- Home Assistant has no single complete public OpenAPI document for every administrative WebSocket surface. The generated base will use official docs plus a curated internal spec; source-derived commands must remain honest about version/installation support.
- Some `ha-mcp` operations depend on its custom Home Assistant component/add-on rather than stock Core APIs. Those rows must use stock REST/WebSocket/Supervisor surfaces where available and report capability-unavailable rather than pretend parity.
- No shipping stubs are proposed. Unsupported capabilities on a user's specific installation fail with typed capability errors.
