# Kie.ai Market Model Catalog

All 122 models below share the same two endpoints:

- Create a task: `kie kie-ai-jobs market-create-task --model <id> --input '{...}'`
- Query a task:  `kie kie-ai-jobs market-query-task --task-id <id>`

This catalog is a point-in-time snapshot from docs.kie.ai, regenerated by `research/build_spec.py` (see README.md for the weekly-refresh mechanism).
