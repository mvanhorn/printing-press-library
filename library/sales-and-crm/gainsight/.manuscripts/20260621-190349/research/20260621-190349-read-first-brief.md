# Gainsight read-first brief

Gainsight was selected as a customer success system with useful read surfaces for customer success data, health scores, Cockpit CTAs, success plans, and timeline activity.

The generated package intentionally emphasizes read-first agent workflows: local sync, search, analytics, command discovery, and MCP access. Live vendor behavior is credential-gated, so local validation covers build health, command surfaces, auth diagnostics, and MCP startup.

The default server URL uses `https://example.gainsightcloud.com` as a placeholder because the public `api.gainsight.com` host resolves to private/internal AWS addresses in this environment. Users should configure their tenant base URL before live calls.
