## Findings

### 1. regen-merge classifies a const↔var declaration change as TEMPLATED-CLEAN, so `--apply` silently overwrites the hand edit (Bug)
- **What happened:** the printed CLI's generated `internal/mcp/bound/bound.go` was hand-edited from the template's `const ( MaxBytes = 60000 … )` to `var MaxBytes = Budget()`, with `Budget()` in a novel file. A regen-merge dry-run classified the file `TEMPLATED-CLEAN`. `apply.go:29` overwrites TEMPLATED-CLEAN files from fresh, so `--apply` would restore the const and silently drop the edit.
  - The same dry-run flagged 13 other files as `TEMPLATED-VALUE-DRIFT`, so value-drift detection works in general. Only this edit shape escapes.
  - The only reason the loss would be noticed is that a CLI-local test assigns `MaxBytes`, which fails vet once it is a const again.
- **Scorer correct?** N/A. No score penalty.
- **Root cause:** regen-merge classifier, `internal/pipeline/regenmerge/`. Verified on origin/main 404c3a3. There is no regenmerge diff since v4.35.6.
  - `value_drift.go:351`, in `genDeclName`: `return decl.Tok.String() + ":" + strings.Join(names, ",")`. Value-drift keys carry the token, so `var:MaxBytes` (published) and `const:MaxBytes…` (fresh) never pair up.
  - `value_drift.go:48-53`, in `detectValueDrift`: an unmatched published decl is skipped, with the comment "The decl-set check upstream already flagged this as TEMPLATED-WITH-ADDITIONS, so we shouldn't be here. Skip defensively."
  - `classify.go` `extractDecls`: `decls.add(n.Name)`. The decl-set check keys by bare name with no token, so `pub.minus(fresh)` is empty and the file is "clean by decl set".
  - Net effect: the invariant the skip relies on is false for a kind change. Both checks pass it through, and `decideBothPresent` returns `VerdictTemplatedClean`.
- **Cross-API check:** independent of the API. Any printed CLI where an operator turns a generated constant into a variable (or the reverse) is exposed. That covers making a timeout, a byte or item cap, a rate limit or a page size env-configurable, which is the most natural edit to a generated constants block. The shape doesn't depend on spec, auth or transport.
- **Frequency:** every API (tool-level, triggered by an edit shape, not by the spec)
- **Fallback if the Printing Press doesn't fix it:**
  - The amend skill's patch-record needles (`markers` / `call_sites` in `.printing-press-patches/*.json`) make `--apply` fail closed via `ValidatePatchRecords` (`apply.go:201-204`), but only if the operator declares a needle for this exact line.
  - The etsy patch record listed the file in `files[]` with no needle. Its presence check passes after the overwrite.
  - Fallback reliability is low. The value-drift classifier exists precisely so that unmarked value edits are not lost, and operators reasonably rely on it.
- **Worth a Printing Press fix?** Yes. Regen silently dropping working code is P1 by the rubric, and the fix is small and local.
- **Inherent or fixable:** fixable.
- **Durable fix:**
  - When the bare-name decl sets match but token-keyed value-drift keys do not pair up, report drift instead of skipping.
  - Either key value-drift comparison by bare name and compare the rendered decl including its token, or treat any token mismatch for the same name as `TEMPLATED-VALUE-DRIFT`.
  - For a multi-spec block where a name moved to a different block or token, compare per name rather than per block.
- **Test:**
  - Positive: fresh has `const MaxBytes = 60000` and published has `var MaxBytes = 60000` (kind change only). The file must classify as `TEMPLATED-VALUE-DRIFT`.
  - Positive: fresh has `const ( MaxBytes = 60000; MaxItems = 50 )` and published has `var MaxBytes = 32000` plus `const ( MaxItems = 50 )`. Same expectation.
  - Negative: identical decls stay `TEMPLATED-CLEAN`.
  - Negative: an in-place `const MaxBytes = 50000` is still `TEMPLATED-VALUE-DRIFT`, as today.
- **Evidence:** reproduced in a scratch clone with `cli-printing-press` 4.35.6, using generate from the CLI's spec with `--mcp-orchestration code`, then `regen-merge <clone> --fresh <tree> --json`. bound.go came back `{"verdict":"TEMPLATED-CLEAN"}`. It was then minimised to two-file trees, each with the generated header on line 1:

  | Case | fresh | published | verdict |
  |---|---|---|---|
  | A | `const ( MaxBytes = 60000; MaxItems = 50 )` | `var MaxBytes = 32000` + `const ( MaxItems = 50 )` | TEMPLATED-CLEAN (escapes) |
  | B (control) | same | `const ( MaxBytes = 50000; MaxItems = 50 )` | TEMPLATED-VALUE-DRIFT |
  | C | `const MaxBytes = 60000` | `var MaxBytes = 60000` | TEMPLATED-CLEAN (escapes) |
  | D | `const MaxBytes = 60000` | `var MaxBytes = 32000` | TEMPLATED-CLEAN (escapes) |
  | E (control) | `const MaxBytes = 60000` | `const MaxBytes = 50000` | TEMPLATED-VALUE-DRIFT |

  Cases A to E were run as dry runs only; `--apply` was never executed. The overwrite is inferred from `apply.go:29` and the verdict.

### 2. Spec-omitted `explode` sends repeated keys to an API that wants comma-joined arrays (Assumption mismatch)
- **What happened:** Etsy's spec declares batch params such as `listing_ids` as `type: array` with no `style`/`explode`. Per OpenAPI 3 the generator defaults form arrays to `explode: true` and sends `?listing_ids=a&listing_ids=b`.
  - Etsy reads one value, so a batch lookup of 3 ids returned 1.
  - The fix was flipping 8 CLI call sites and 9 code-orch bindings to `explode=false`.
- **Root cause:** the generator follows OpenAPI defaults correctly. `parser.go:4694-4703` uses `parameter.SerializationMethod()`, and `generator.go` `queryParamExplodes` defaults nil to true. #3437 / PR #3583 made this an explicit model. The vendor's spec simply omits `explode: false`.
  - There is no `x-pp-*` extension or override for `style`/`explode`. The only remedy is editing the spec before generate.
- **Cross-API check:** youtube's spec declares `explode: true` on `part`/`id` while its descriptions say "comma-separated list". Its printed CLI predates #3583 and sends comma strings today, so a reprint would switch it to repeated keys.
  - Whether the YouTube API accepts repeated keys is unverified.
  - ticketmaster has `explode: true` array params, with weaker evidence.
  - spotify models `ids` as a comma string, so it is not affected.
- **Disposition:** Skip (Step B). Only one API has observed breakage, and the generator's behaviour is spec-correct.
  - **Refile condition:** verify a youtube reprint against the live API. If repeated `part=` or `id=` values are dropped, that is a second API with evidence. File then for a per-param `x-pp-query-explode` override, or for a live-dogfood check that a batch-by-ids endpoint returns N results for N ids.

### 3. The cobratree shell-out mirror path returns a non-resumable preview over budget (Discovered optimization)
- **What happened:** hand-built (novel) commands exposed over MCP go through `cobratree/shellout.go`, which wraps stdout in `bound.Text`. Over `MaxBytes` (60000), that returns `previewEnvelope(…)`, a bounded, non-resumable preview.
  - The typed, store and sql paths do have `next_cursor` paging since the #3090 epic (closed 2026-06-25; PRs #3214, #3230, #3234, #3239, #3240, #3260).
  - Market-research tools on this CLI exceed the budget, and an agent couldn't page them.
  - The CLI added a JSON-aware mirror pager with a cursor that re-executes the command.
- **Disposition:** Skip (Step G).
  - #3090's acceptance explicitly allows "a canonical bounded preview envelope [that] says it is not resumable" for opaque output.
  - PR #3186 (shell-out bounding) was closed unmerged.
  - Observed harm is on one CLI. Narrowing flags (`--limit`) are the designed fallback.
  - A maintainer would plausibly close this as working as designed.

## Work Units

### WU-1: Classify declaration-kind changes in templated files as value drift (from F1)
- **Stable ID:** WU-1
- **Priority:** P1
- **Type:** bug
- **Component:** generator
- **Goal:** regen-merge never classifies a templated file `TEMPLATED-CLEAN` when a same-named top-level declaration differs between published and fresh, including a change of `const`/`var` token or block.
- **Target:** `internal/pipeline/regenmerge/value_drift.go` (`genDeclName`, `detectValueDrift`) and `classify.go` (`extractDecls`, `decideBothPresent`).
- **Acceptance criteria:**
  - Positive: in the five-case table, cases A, C and D classify `TEMPLATED-VALUE-DRIFT`, with the differing decl named in `value_drift.decls`.
  - Positive: `--apply` on case D leaves the published `var` decl in place (or stops for manual merge). It does not overwrite.
  - Negative: identical files stay `TEMPLATED-CLEAN`.
  - Negative: cases B and E keep today's `TEMPLATED-VALUE-DRIFT` output.
  - Negative: a full regen-merge over an unchanged printed CLI produces the same verdict counts as before.
- **Scope boundary:**
  - Does not add `explode` overrides.
  - Does not change the patch-record needle mechanism.
  - Does not change function-body drift detection, which has its own documented limits.
- **Dependencies:** None.
- **Complexity:** small

## Anti-patterns
- **Writing "not landed" from the template alone.** The operator's session report said the bounding epic "never landed in the machine" because `mcp_bound.go.tmpl` still had `MaxBytes = 60000`. The epic had in fact shipped cursor paging for the typed paths. The gap was only the mirror path and the env budget. Check the issue state and merged PRs before characterising upstream.
- **Declaring a hand-edited generated file in a patch record with `files[]` only.** A file-presence check survives the overwrite it is meant to guard. Declare a `markers` needle on the load-bearing line.

## What the Printing Press Got Right
- **Explicit array serialization (#3437 / PR #3583).** Fixing Etsy's arrays took one parameter flip per site, with no hand-written encoding.
- **Value-drift detection.** It caught 13 in-place value edits in a 495-file tree. Only the kind-change shape escaped.
- **Patch-record needles.** `ValidatePatchRecords` runs on the staged merge before the swap, so a declared needle fails closed.
- **The #3090 typed-path contract.** Cursors, preview envelopes and one budget are in place and coherent, and the mirror-path adoption built on them.
