# Twitter CLI

Twitter OpenAPI(Swagger) specification

## Install

### Go

```
go install github.com/mvanhorn/printing-press-library/library/social-and-messaging/twitter/cmd/twitter-pp-cli@latest
```

### Binary

Download from [Releases](https://github.com/mvanhorn/printing-press-library/releases).

## Quick Start

### 1. Install

See [Install](#install) above.

### 2. Set Up Credentials

Get your API key from your API provider's developer portal. The key typically looks like a long alphanumeric string.

```bash
export TWITTER_ACCEPT="<paste-your-key>"
```

You can also persist this in your config file at `~/.config/twitter-pp-cli/config.toml`.

### 3. Verify Setup

```bash
twitter-pp-cli doctor
```

This checks your configuration and credentials.

### 4. Try Your First Command

```bash
twitter-pp-cli 1-1 get-friends-following-list
```

## Output Formats

```bash
# Human-readable table (default in terminal, JSON when piped)
twitter-pp-cli 1-1 get-friends-following-list

# JSON for scripting and agents
twitter-pp-cli 1-1 get-friends-following-list --json

# Filter to specific fields
twitter-pp-cli 1-1 get-friends-following-list --json --select id,name,status

# Dry run — show the request without sending
twitter-pp-cli 1-1 get-friends-following-list --dry-run

# Agent mode — JSON + compact + no prompts in one flag
twitter-pp-cli 1-1 get-friends-following-list --agent
```

## Agent Usage

This CLI is designed for AI agent consumption:

- **Non-interactive** - never prompts, every input is a flag
- **Pipeable** - `--json` output to stdout, errors to stderr
- **Filterable** - `--select id,name` returns only fields you need
- **Previewable** - `--dry-run` shows the request without sending
- **Retryable** - creates return "already exists" on retry, deletes return "already deleted"
- **Confirmable** - `--yes` for explicit confirmation of destructive actions
- **Piped input** - write commands can accept structured input when their help lists `--stdin`
- **Offline-friendly** - sync/search commands can use the local SQLite store when available
- **Agent-safe by default** - no colors or formatting unless `--human-friendly` is set

Exit codes: `0` success, `2` usage error, `3` not found, `4` auth error, `5` API error, `7` rate limited, `10` config error.

## Use as MCP Server

This CLI ships a companion MCP server for use with Claude Desktop, Cursor, and other MCP-compatible tools.

### Claude Code

```bash
claude mcp add twitter twitter-pp-mcp -e TWITTER_ACCEPT=<your-key>
```

### Claude Desktop

Add to your Claude Desktop config (`~/Library/Application Support/Claude/claude_desktop_config.json`):

```json
{
  "mcpServers": {
    "twitter": {
      "command": "twitter-pp-mcp",
      "env": {
        "TWITTER_ACCEPT": "<your-key>"
      }
    }
  }
}
```

## Troubleshooting
**Authentication errors (exit code 4)**
- Run `twitter-pp-cli doctor` to check credentials
- Verify the environment variable is set: `echo $TWITTER_ACCEPT`
**Not found errors (exit code 3)**
- Check the resource ID is correct
- Run the `list` command to see available items
