An explicit scope choice

Approve the reader scope means accepting the following trim from the wider ecosystem:

  • Source writes: sending/replying, media upload, mark read, archive, delete and settings changes.
  • Realtime/push listeners, Matrix bridging, separate Google contacts lookup and binary media download.
  • Background-service installation and integration into the existing relationship-memory database.

These features will be absent, with no stub commands. Calls and dedicated voicemail-folder access are not verified.

The consumer web protocol can change and sessions can expire. The CLI must report incomplete collection honestly; an empty search or one successful sync cannot prove all history is collected.

Before this can ship

Implement the verified positional-array protocol, private session signing and page-safe SQLite storage. Then prove live pagination, account isolation, unchanged read state, repeat-import deduplication and all five local queries. Promotion requires the Printing Press shipcheck and live test matrix.
