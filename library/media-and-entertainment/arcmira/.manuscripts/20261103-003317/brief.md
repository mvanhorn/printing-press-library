# Transcript quote sheets

Reporters and editors often search the same topic with several phrases. A passage can appear in several result files. The quote-sheet command combines them into one local sheet and keeps every matching query beside the source link, timestamp and original wording.

The command accepts the public transcript search response and the printed CLI’s JSON envelope. It preserves the first-seen order of passages and reports conflicting snapshots of the same passage before writing output.
