# printgoat Absorb Manifest

Sources catalogued: `nukleas/thingfinder` (npm, CLI+lib+MCP, closest direct competitor — read at source level), `pikalover6/3dfetch` (npm, 16-source provider library, no CLI), `GhostTypes/printables-cli-api` + `printables-mcp-server`, `pattonwebz/CultsDL`, `jcarolinares/thingiverse_downloader`, the Thingiverse browser-extension cluster (Thingiverse++, Thingiverse Fixer, Better Thingiverse Download, thingiverse-easy-download), `lostprojects/3MF-Agent-Tools` model-finder skill, `gerolori/printables-batch-downloader`, native site features (Printables/Thingiverse/Cults3D search & browse UI).

Explicitly out of scope (different product category, noted for awareness only, not absorbed): `SourceBox-LLC/PrintMCP`/`PrintPal` (search→slice→print pipeline requiring CuraEngine/OctoPrint) and the `claw3d` ecosystem (AI-generate→slice→print) — printgoat is a discovery/download tool, not a slicer/print-farm controller.

## Transcendence (only possible with our approach)

Persona model (from the Step 1.5c.5 subagent): P1 "Hobbyist Comparator" (can't tell which cross-site results are the same design at what price/license), P2 "Print-Farm Operator" (needs crash-resumable multi-host batch jobs + provenance proof), P3 "Duplicate-Averse Archivist" (years of unsorted STLs, no idea what's already owned or what's been delisted), P4 "Iterative Maker/Designer-Watcher" (tracks print failures, follows designers who post inconsistently across sites).

18 candidates generated, 8 cut (fake-resume reframed away, taxonomy-reconciliation folded into matching logic, remix-lineage killed for unverifiable data, price-alerts folded into `history diff`, offline-cache-search killed as non-cross-source, "best version" auto-picker cut for padding risk, plus 2 folded into sibling commands as sub-behaviors). 10 survivors, all `hand-code`, all scoring >=6/10.

| # | Feature | Command | Buildability | Why Only We Can Do This | Long Description |
|---|---------|---------|--------------|--------------------------|-------------------|
| 1 | Cross-source duplicate/value detection | `duplicates <query>` | hand-code | Only a local index holding normalized results from all three schemas at once can fuzzy-match title/dimensions/file-count to flag the same design listed free on one site and paid on another. | Finds designs that appear to be the same physical object across two-plus sources; normalized side-by-side of price/license/formats. Unlike `search`, performs the cross-source join. |
| 2 | License compliance audit | `license audit [--library \| <id>]` | hand-code | Joins each library item's site-reported license against a locally stored "intended use" tag — no API knows what you plan to do with a file you already own. | Scans one item or the whole local library against a declared usage intent (e.g. `--intent commercial`) and flags conflicts. |
| 3 | Local history diff / staleness | `history diff <id>` (`--all` alias `history stale`) | hand-code | Upstream APIs only return current state; only a local timestamped snapshot gives something to diff against. | Compares current remote state (files/version/price/license) against last locally cached snapshot. `--all` lists every watched item that has drifted. |
| 4 | Library health / link-rot report | `library doctor` | hand-code | Cross-references on-disk manifest + local downloads table + live remote existence re-check — a single-site tool never tracks files it didn't source. | Reports orphaned local files, missing-but-expected files, byte-identical duplicate downloads, and remote items since delisted (unrecoverable if lost locally). |
| 5 | Failure-informed re-search | `similar <id>` (paired with `log fail <id> --reason ...`) | hand-code | Print outcome is data no API collects (happens on your printer after download); only a local outcome log lets re-search exclude/downweight a bad result and its designer. | Re-runs cross-source search seeded from a logged failed print, excluding that item and down-ranking same-designer/same-geometry results. |
| 6 | Cross-site designer following | `follow designer add/list` + `feed` | hand-code | Unified feed built from a user-declared table linking one person's accounts across 3 unrelated user-ID systems, polled locally — no site knows the others exist. | Tracks designer aliases explicitly linked across sources, surfaces new uploads from any of them in one feed. Alias linking is manual, not inferred. |
| 7 | Format-availability gap finder | `formats gaps <id>` | hand-code | Compares one model's file-format list against every other locally indexed, similarly-tagged result — a join no single site's file endpoint can perform. | Flags a model offering only one format (e.g. STL, no 3MF/STEP) and searches locally indexed alternatives that include the missing format. |
| 8 | Cross-source resumable batch job | `job download` / `job resume <job-id>` | hand-code | A job pulling files from 3 hosts with 3 auth schemes and 3 rate limits needs one local manifest tracking byte-offset per file per source — no single-site downloader models "a job spanning hosts." | Resumes an interrupted multi-source download job using per-file byte-range state, replacing the filename-exists heuristic that leaves orphaned `.partial` files. |
| 9 | Print-job version pinning | `snapshot create <name> <ids...>` / `snapshot verify <name>` | hand-code | Pins exact file hashes/source/version used for a specific print run locally so a reprint months later can detect drift — remote APIs never expose their own past state. | Freezes file hashes/metadata used for a named job; `snapshot verify` later confirms local files unchanged and warns if upstream has since updated. Distinct from `history diff` (general drift) via its tie to a specific past run. |
| 10 | Personal designer reliability score | `designer stats <name>` | hand-code | Aggregates the user's private print-outcome log by designer across all 3 sites — a signal no platform collects (post-download print outcomes). | Reports your own success/fail rate and common failure reasons for a designer, pooled across whichever sites they publish on. Not the same as site-level popularity counts. |

**Hand-code commitment: 10 of 10 transcendence features require hand-written Go** (local joins, historical state, or cross-host job management — none of these can be generator-emitted typed endpoint commands). Each is estimated at roughly 50-150 LoC plus root.go wiring per the printing-press Phase 3 convention, so this is a substantial hand-build on top of the absorbed/generated surface — call this out explicitly at Phase Gate 1.5.
