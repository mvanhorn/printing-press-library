# Rocket League Tracker CLI — Absorb Manifest

> Generated by Phase 1.5 of the printing-press skill. The absorbed table covers
> every feature any competing tool offers; the transcendence table covers
> features only this CLI can build because of its local SQLite store, agent-shape,
> and shared identity model with the surrounding rocket-league-stats project.

## Tools surveyed (Step 1.5a)

- **Direct API wrappers (RapidAPI):** yataknemogy/rocket-league-api (TS, REST front for RapidAPI), AngaBlue's RapidAPI walkthrough.
- **TRN-scraping wrappers (deprecated/dead):** PannH/trn-rocket-league (npm, archived 2025-11), kilroy-2/rl-rank-stats-web-scrap (Python, broken since 2023-04 Cloudflare protection), hugogrochau/rocket-league-apis-client (npm, dormant), dev-ruby/TrackerGG (Ruby, generic).
- **CLIs:** Scetch/rlstats-cli (Rust, archived 2025-08; backed RocketLeagueStats which shut down).
- **Discord bots / trackers:** jubishop/Tusk (Ruby, ballchasing-based), jeremyd4500/RL-Stats (JS, TRN), capierc3/RL_Bot, GuyBanks/TuskBot, luukdg/FlipReStat (cloudscraper TRN), prayansh/RLDiscordBot, ctedrick/discord-rl-bot, Skyl3r/Calculated.gg-bot, BlancoLanda/LandasRLTracker (log-file scraper + Twitch overlay), trew/RankTracker (log-file scraper, Java), kapezit/rl_tracker (bulk MMR check).
- **Adjacent (replays, RL ML, esports):** SaltieRL/carball, tfausak/rattletrap, jamieweavis/prosper, joshua-arts/rocket-league-stats-api (parallel.gg/RLCS GraphQL), amas0/octanegg (RLCS Python), rlapi (Jackenmen, closed-beta Psyonix). Out of CLI's scope (replay parsing / RLCS-only).
- **MCP servers:** none for Rocket League. Generic sports MCPs exist (NFL/NBA/NHL).
- **Claude plugins/skills:** none for Rocket League.

## Transcendence (only possible with our approach)

Features only this CLI can build because it has local SQLite snapshots, agent-shaped output, and shares the surrounding rocket-league-stats project's identity model.

| # | Feature | Command | Score | Why Only We Can Do This | Persona |
|---|---------|---------|-------|------------------------|---------|
| 1 | Daily snapshot delta | `peek <player>` | 9/10 | Reads last two `playlists` snapshots from local SQLite for each playlist key; prints today vs yesterday MMR delta + tier change in one line. No website gives a day-over-day delta as a one-liner. | Mason |
| 2 | Time-series MMR curve | `trend <player> --playlist <k> --days N` | 9/10 | Groups local `playlists` snapshot rows by day for the chosen playlist_key; emits MMR series as JSON or CSV. Cannot be answered with a single API call. | Mason, Devi |
| 3 | Session summary | `session-summary <player>` | 8/10 | Filters local snapshots to rows captured since the local day boundary; computes start vs current MMR + W/L count + most-played playlist. Mirrors `session-window.ts` pattern from this project. | Mason |
| 4 | Group ranker | `group <name> [--rank-by mmr-delta-7d \| win-delta-7d \| mvp-delta-7d]` | 8/10 | Reads saved group membership from local SQLite, joins per-member snapshots, computes the chosen delta over N days. No public site offers a friend-group diff view. | Priya |
| 5 | Save a friend group | `group save <name> <player>...` / `group list` | 6/10 | Inserts rows into local `groups` and `group_members` tables keyed by storage_key. Required scaffolding for #4. | Priya, Theo |
| 6 | Agent context blob | `agent-context <player> [--days 30] [--select fields]` | 9/10 | Joins local `players` + last-N `playlists` snapshots + last-N matches into a single agent-shaped JSON envelope. `--select` whitelists keys for token-budget control. | Devi |
| 7 | Promo distance | `promo <player>` | 7/10 | Calls `/ranks/{playerId}`, computes `(MMR_next_tier - current_MMR) / avg_mmr_per_win` against a baked-in static MMR-ladder reference. No wrapper computes promo distance. | Mason |
| 8 | Tournament fit | `tournament-fit <player>` | 6/10 | Joins `/ranks/{playerId}` with `/tournaments`, filters tournaments to those whose skill bracket contains the player's MMR. The cross-call join is what no single endpoint supplies. | Mason |
| 9 | Best queue time | `population-best-time --playlist <k> [--days 7]` | 5/10 | Aggregates locally-stored `population` snapshots by hour-of-week; returns the peak hour. Single `/population` call only gives "right now." | Mason |
| 10 | MMR sparkline | `mmr-curve <player> --playlist <k>` | 6/10 | ASCII sparkline of MMR over last 30 days; same series as `trend`, formatted for terminal use. | Mason |
| 11 | Liar check | `liar-check <player> --claimed-rank <tier>` | 5/10 | Compares per-playlist MMR to the static MMR-ladder lower bound for `<tier>`; returns "true" or "overstated by N MMR." | Priya |
| 12 | Import collector snapshot | `import-collector-snapshot <path>` | 7/10 | Reads JSON exported by the rocket-league-stats `apps/collector` process, upserts rows into local store keyed by the shared storage_key. Uniquely possible because of the surrounding project. | Devi |

## Stubs / Known Gaps

- **#22 Recent announcements** may not exist on the RapidAPI listing despite the docs page mentioning it. If endpoint validation fails in Phase 5, marked as `(stub — not present on listing)` in the README.
- **#16 Stat leaderboard** scope: only standard public stats (goals, wins, MVPs, saves, assists, shots) are guaranteed; exotic stats may 404.
- Live smoke testing in Phase 5 will be skipped unless the user provides `RAPIDAPI_KEY` before that phase.
- The upstream RapidAPI listing is community-maintained and may go dark; the CLI's `doctor` command will surface this.
