## Dependency notes

- Plan 001 has no dependencies. It is the first slice for making `figma-pp-cli` more Mario/agent friendly without changing authentication, write surfaces, or the generated Figma REST commands.
- Plan 002 depends on 001: it reuses `parseFigmaRef`, `buildAgentNodeIndex`, `scoreAgentNode`, `agentMatch`, and `agentNextSteps`. It collapses the prompt→screenshot pipeline into one read-only `agent shot` call that resolves a label (or URL node-id), filters to screen-like nodes, renders, and downloads PNGs to local files (with URL fallback). Key risk is the render CDN being a non-`api.figma.com` host; the command degrades to URL-only when that host is not reachable through an egress gateway.
